## About
The Plant Shop app allows users to interact with a plant inventory catalog. Built as part of a React frontend curriculum, this project demonstrates component hierarchy, state management, asynchronous data fetching (`useEffect`), form handling (`POST` requests), and real-time array filtering.

## Features
- **Browse Catalog:** View all available plants fetched dynamically from a local backend server upon page load.
- **Add New Plants:** Submit a form with a plant name, image URL, and price to instantly add it to the inventory.
- **Stock Status Toggle:** Mark individual plants as "In Stock" or "Sold Out" directly on their cards.
- **Real-Time Search:** Filter plants instantly by name using a search bar input.

## Technologies Used
